**踩过的坑**
- Git Bash 在本机不可用（shim 缺 dirname/cat/ls），改用 PowerShell 工具跑命令。
- PowerShell 用 `& npm.cmd` 而非 `npm`；输出重定向到文件再 Read 才能看到中文。
- PowerShell 控制台显示中文会乱码，但文件内容本身是正确 UTF-8，不要误判为编码问题。
- `tsx` 下顶层 `await` 在非 async 函数里会报 TransformError。
- 给 `PROTOCOL_META` 加 `as const` 会把 status 收窄成字面量，导致冻结校验变死代码
  （tsc TS2367）——导出时用 interface 而不是 as const。
