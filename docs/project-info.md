## 第 4.2 节的设计约束（提醒）

- **协调系统与目标业务仓库必须分开**：业务 agent 不应能通过修改协调器或 CI
  来降低自己的验收门槛。
- 首次验收可建立一个非常小的目标示例仓库；验收后再注册真实业务仓库。
- 目标项目可使用任何适合的业务技术栈；协调系统使用 TypeScript，
  以便在 Worker 和 Windows Node.js 执行器之间共享协议。
