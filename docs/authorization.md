# 授权记录

依据《项目书》第 11 节："授权记录只保存非敏感范围与确认依据。
相同有效范围不重复询问；新增高权限操作不得自动扩展许可。"

**本文件不得包含任何凭据、token、私钥或登录文件内容。**

---

## 授权记录格式

每条授权记录包含：

```yaml
- id: AUTH-0001
  scope: task_branch_push          # 授权范围标识
  target:                          # 准确对象
    repo: <REPO_URL>
    branch_prefix: task/
  granted_at: 2026-09-21T10:40:00+08:00
  expires_at: 2026-10-21T00:00:00+08:00   # 有效期，可空
  basis: "用户在对话中明确同意"               # 确认依据，非敏感描述
  status: active | expired | revoked
```

## 待用户确认的事项

以下事项因缺少必要信息而无法执行，需要用户提供后才能推进：

1. **远程仓库地址** — `<COORDINATOR_REPO_URL>` 与 `<TARGET_REPO_URL>` 均未提供。
   在获得地址与明确授权前，不执行任何 `git push`。
2. **Cloudflare 资源所有者** — 第 4.2 节要求指定一人负责计费与部署授权。
3. **每日预算与停止条件** — `<DAILY_BUDGET_AND_LIMITS>` 未填。
   第 15 节要求上线前按实际账号核对额度，设置任务次数、执行时间、返修次数、
   CI 次数和账单预算。
4. **是否启用 Syncthing** — `<SYNCTHING_ENABLED>` 未定，属 P6 可选范围。

## 不扩展原则

- 相同有效范围不重复询问。
- **新增高权限操作不得自动扩展许可**：例如已授权"任务分支 push"**不等于**已授权
  "自动合并"或"CI 配置修改"。
- 未授权的操作一律拒绝，并标记为 `blocked_approval`。
